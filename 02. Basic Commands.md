### Basic Linux Commands

**Command**	          **Description**	                                     **Example**
    pwd	            Displays the current working directory.	                    pwd
    ls	            Lists files and directories in the current location.	    ls
    cd	            Changes the current directory.	                            cd Documents
    mkdir	        Creates a new directory (folder).	                        mkdir projects
    touch	        Creates a new empty file.	                                touch notes.txt
    cp	            Copies files or directories.	                            cp file.txt backup.txt
    mv	            Moves or renames files and directories.	                    mv old.txt new.txt
    rm	            Removes files or directories.	                            rm file.txt

### Useful command variations

| **Command**            |	         **Purpose**                                     |
| ls -l	                |   Displays files with detailed information.                |
| ls -a	                |   Displays hidden files too.                               |
| cd ..	                |   Moves one directory backward (to the parent directory).  |
| cd ~	                |   Moves to the home directory.                             |
| mkdir -p a/b	        |   Creates nested directories.                              |
| cp -r folder1 folder2	|   Copies a directory recursively.                          |
| mv file.txt Documents/|	Moves a file into Documents.                             |
| rm -r folder	        |   Removes a directory and its contents.                    |
