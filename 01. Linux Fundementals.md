### What is Linux?
Linux is a free, open-source operating system kernel, first created by Linus Torvalds in 1991. Strictly speaking, "Linux" is just the kernel: the core piece of software that manages hardware (CPU, memory, disks, network) and lets programs run on top of it. When people say "Linux" in everyday use, they usually mean a complete operating system built around that kernel, which is properly called a Linux distribution

### What is Linux Ditribution(or Distro) ?
A Linux distribution (or "distro") is a complete operating system built around the Linux kernel. The kernel alone can't do much for a normal user, so a distro bundles it with everything else needed to actually use a computer.

#### What's inside a distro
- Linux kernel: manages hardware and system resources
- Core system tools: the shell, file utilities, and libraries (many from the GNU project)
- Package manager: installs, updates, and removes software
- Init system: starts services at boot (usually systemd)
- Desktop environment (optional): GNOME, KDE, XFCE, and so on, for a graphical interface
- Default applications: browser, text editor, and similar tools

### Why so many distros exist
Because Linux is open source, anyone can package these components differently. Each distro makes its own choices about what to include, how often to update, and who it's meant for.

### What is kernel?
The kernel is the core part of an operating system. It sits between your hardware and your programs, and it controls how they share and use the computer's resources.

#### What the kernel does
- Process management: decides which programs run, when, and for how long on the CPU
- Memory management: gives each program its own memory and keeps them from interfering with each other
- Device management: talks to hardware (disks, network cards, keyboards, USB devices) through drivers
- File system management: handles how data is stored and retrieved on disks
- Security and permissions: controls who can access which files and resources
- System calls: provides the interface programs use to ask the hardware for things, such as reading a file or opening a network connection

##### How it fits together
```
Applications  (browser, nginx, docker)
      ↓  system calls
   Kernel
      ↓  drivers
   Hardware  (CPU, RAM, disk, network)
```
