### File Permissions
File permissionin Linux determine who can read, write and Execute a file or directory.

Linux uses three type of permissions and categories of users.

#### 1. Types of file permissions
There are three basic permissions:

- Read     `r`    Allows you to read or view the file content.
- Write    `w`    Allows you to modify the file content.
- Esecute  `x`    Allows you to execute file or program.

#### 2. Categories of users
Linux divides permissions into three categories:

- Owner  `u`  User who owns the file.
- Group  `g`  Users belonging to the file's group.
- Others `o`  Everyone else.

#### 3. Understanding file permissions
Execute:
```ls -l
```
Example Output:
```
-rwxr-xr--
```
```
rwx    r-x   r--
Owner Group Others
```

- Owner(rwx): Read, Write, Execute
- Group(r-x): Read and Execute
- Others(r--): Read Olny

#### 4. How to change file permission
Linux provides the `chmod` command.

Example:
```
chmod u+x script.sh
```
This gives the file owner permission to execute the script.

```
chmod u+w file.txt
```
Adds write permission for the owner.

```
chmod g+r file.txt
```
Adds read permission for the group.
```

```
chmod o-r file.txt
```
Removes read permission from others.
```

#### 5. Numeric permissions
| Number | Permission |

|---     |---         |

| 4      | Read (r)   |

| 2      | Write (w)  |

| 1      | Execute (x)|

| Number    | Permission             |

|---        |---                     |

| 7         | Read + Write + Execute |

| 6         | Read + Write           |

| 5         | Read + Execute         |

| 4         | Read only              |

Example:
```
chmod 755 script.sh
```
- Owner: 7 = Read + Write + Execute.
- Group: 5 = Read + Execute.
- Others: 5 = Read + Execute.

#### 6. Important Linux commands

| Command       | Purpose                             |
|---            |---                                  |
| `ls -l`       | View file permissions               |
|---            |---                                  |
| `chmod`       | Change file permissions             |

| `chown`       | Change file ownership               |

| `chgrp`       | Change group ownership              |

| `umask`       | Set default permission restrictions |
